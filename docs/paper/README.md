# ForestGuard AI Research Paper — Overleaf Compilation Guide

This folder contains the complete academic research paper in **IEEE conference two-column format**.

---

## 📄 File Contents
- `forestguard_paper.tex`: Main LaTeX source document using `IEEEtran` document class.
- `references.bib`: Verified BibTeX citation database with genuine publications (D-Fire, MobileNetV2, YOLO, PyTorch, ONNX Runtime).
- `forestguard_paper.md`: Markdown copy of the paper for quick reading and reference.

---

## 🚀 How to Compile on Overleaf (Free)
1. Go to [overleaf.com](https://www.overleaf.com) and log in.
2. Click **New Project** $\rightarrow$ **Upload Project**.
3. Create a zip of the `docs/paper/` directory containing `forestguard_paper.tex` and `references.bib`, and upload it.
4. Click **Recompile** in Overleaf.
5. The PDF is generated in standard IEEE two-column conference layout ready for download and submission!
